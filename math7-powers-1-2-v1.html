Key idea

A power has a base and an exponent. The exponent tells how many times to use the base as a factor: 2⁴ = 2 × 2 × 2 × 2 = 16. Any number to the first power is that number, and any number (except zero) to the zero power is 1.

This page explains each kind of question once. Exercises that repeat the same question are explained together, because the method is the same.

1. Name the base and the exponent Vocabulary; picture on page 8

The question: “In 2⁴, which number is the base and which is the exponent?”

How to solve it:

  1. Look at the picture on page 8: the arrow marked “Base” points to the big number, the arrow marked “Exponent” points to the small raised number.
  2. The exponent tells how many times to use the base as a factor.
Worked example (book). In 2⁴ the base is 2 and the exponent is 4: 2⁴ = 2 × 2 × 2 × 2 = 16.

The core idea: a power has a base (the factor) and an exponent (how many times the factor is used).

2. Find the value of a power Example 1; exercises 1–3, 10–12, 14–16, 18, 19, 21

The question: “Find the value of 3⁴.”

How to solve it:

  1. Read the base and the exponent: the base is 3 and the exponent is 4.
  2. Use the base as a factor as many times as the exponent says: 3 × 3 × 3 × 3.
  3. Multiply two at a time: 3 × 3 = 9, 9 × 3 = 27, 27 × 3 = 81.
  4. Do not multiply the base by the exponent (3 × 4 = 12 is wrong).
Worked example (book). 5² = 5 × 5 = 25 and 2⁶ = 2 × 2 × 2 × 2 × 2 × 2 = 64.
Exercise 15. 3⁴ = 3 × 3 × 3 × 3 = 81.

The core idea: the exponent counts the factors; it is not a multiplier.

3. First power and zero power Exercises 4, 13, 17, 20; rules on page 8

The question: “Find the value of 9⁰.” / “Find the value of 30¹.”

How to solve it:

  1. Any number to the first power is equal to that number: 30¹ = 30.
  2. Any number to the zero power, except zero, is equal to 1: 9⁰ = 1.
  3. Zero to the zero power is undefined.
Worked example (book). 6¹ = 6, 13¹ = 13, 25¹ = 25; 6⁰ = 1, 10⁰ = 1, 19⁰ = 1.
Exercise 13. 1⁰ = 1.

The core idea: learn the two rules: ¹ gives the same number, ⁰ gives 1.

4. Write a number with an exponent and a given base Example 2; exercises 5–8, 22–30

The question: “Write 81 using an exponent and the base 3.”

How to solve it:

  1. Write the number as a product of equal factors using the given base: 81 = 3 × 3 × 3 × 3.
  2. Count the factors: 3 is used 4 times.
  3. Write the base with the exponent: 3⁴.
  4. Special cases: 4 base 4 is 4¹, and 1 base 7 is 7⁰.
Worked example (book). 49 = 7 × 7 = 7²; 81 = 3 × 3 × 3 × 3 = 3⁴.
Exercise 26. 32 = 2 × 2 × 2 × 2 × 2 = 2⁵.

The core idea: count how many times the base is a factor: that count is the exponent.

5. Two ways to write a number with powers Exercises 32–35

The question: “Give two ways to represent 64 using powers.”

How to solve it:

  1. Find a number that, multiplied by itself, gives 64: 8 × 8, so 8².
  2. Look for a different base: 4 × 4 × 4 = 64, so 4³ (also 2⁶).
  3. Write two different powers; check each one by multiplying.
Exercise 34. 64 = 8² = 4³ (also 2⁶).

The core idea: a number can have several power forms with different bases.

6. Find the value of an expression with powers Exercises 36–44

The question: “Find the value of 3² + 4².”

How to solve it:

  1. Work out each power first: 3² = 9 and 4² = 16.
  2. Then add or subtract from left to right: 9 + 16 = 25.
  3. Remember the rules: ¹ keeps the number and ⁰ gives 1.
Exercise 44. 3³ + 4² − 5¹ = 27 + 16 − 5 = 43 − 5 = 38.

The core idea: powers first, then add, subtract or multiply.

7. Word problems with powers Example 3; exercises 9, 31, 46–49

The question: “A contestant had 1 point and tripled his score every turn for four turns. Write his score as a power and find it.”

How to solve it:

  1. Find what repeats: the score is tripled again and again.
  2. Count how many times: four turns.
  3. Write the repeated factor as a power: 3⁴, then work it out: 3 × 3 × 3 × 3 = 81.
  4. For doubling problems use the base 2; for earthquake steps use the base 10.
Worked example (book). Great is 3 steps above moderate: 10 × 10 × 10 = 10³ = 1 000 times stronger.
Exercise 49. 1 hour = 2 divisions: 2² = 4 cells; 2 hours: 2⁴ = 16; 3 hours: 2⁶ = 64.

The core idea: the repeated multiplier is the base and the number of repeats is the exponent.

8. Cube volume and edge Exercises 45, 52

The question: “What is the volume of a cube that is 6 cm long on an edge?”

How to solve it:

  1. The volume of a cube is its edge to the third power.
  2. Use the edge as a factor 3 times: 6 × 6 × 6 = 216.
  3. To find the edge from the volume, look for the number whose third power is the volume (10³ = 1 000).
Exercise 45. 6³ = 216 cm³. Exercise 52. the edge is 10 m.

The core idea: volume uses the third power; the edge is the base.

9. What’s the error? and compare powers Exercises 50, 51

The question: “A student wrote 64 as 8 × 2. What did the student do wrong?” / “Is 2⁵ greater than or less than 3³?”

How to solve it:

  1. For the error: work out what the student calculated (8 × 2 = 16) and what the power should be (8 × 8 = 8²).
  2. To compare powers: work out each value (2⁵ = 32, 3³ = 27), then compare the numbers.
Exercise 50. The student multiplied the base by the exponent. 64 = 8 × 8 = 8².Mine, not from the book
Exercise 51. 32 is greater than 27, so 2⁵ is greater than 3³.

The core idea: never compare powers by their bases or exponents alone: work out the values.

10. Think and Discuss Think and Discuss 1–3

The question: “Describe the relationship between 3⁵ and 3⁶.” / “Which power of 8 is equal to 64?” / “Why is a number to the first power equal to itself?”

How to solve it:

  1. Count how many times the base is a factor in each power.
  2. For 8²: 8 × 8 = 64.
  3. For the first power: the base is used as a factor only once.
Think and Discuss 1. 3⁶ has one more factor of 3 than 3⁵, so 3⁶ = 3 × 3⁵ (729 = 3 × 243).Mine, not from the book

The core idea: use your own words; many answers are correct.

11. Spiral review: add, divide, round Exercises 53–67 (previous courses)

The question: “Round 1 720 to the nearest 100.” / “Estimate 113 000 − 79 000.”

How to solve it:

  1. Adding a list: add in order, or pair numbers that make tens.
  2. Dividing: use the multiplication fact (9 × 7 = 63).
  3. Rounding: look at the digit to the right of the place; 5 or more rounds up.
  4. Estimating a difference: round each number first, then subtract.
Exercise 65. 1 720 is closer to 1 700 than to 1 800, so it rounds to 1 700.

The core idea: round first, then calculate.
